# Visit Counter

A small Python HTTP application backed by Redis, built as a DevOps internship
exercise. The project will include Docker Compose, a Bash health check,
automated tests and GitHub Actions CI.

## Implementation plan

1. Implement the HTTP endpoints and automated tests.
2. Add a non-root Docker image and persistent Redis service.
3. Develop the Bash health check on a feature branch and merge a pull request.
4. Add CI and verify the complete setup from a fresh clone.

Implementation and verification notes will be added as each step is completed.
